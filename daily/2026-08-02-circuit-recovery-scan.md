# KCL·KVL과 노드 해석 복원 스캔

## 목표
- 전자회로 복원 모드에서 KCL, KVL, Node Analysis의 현재 기억 상태를 확인한다.

## 예측 — 내가 먼저 답한 것
- "KCL은 회로에서 전류에 대한 공식이야. 전류가 들어온 만큼, 전류가 나온다는 것이 기본적인 개념이며, 회로의 특정 부분을 기준으로 전류가 내부로 들어오는 양이 x라고 하면, 외부로 빠져나가는 양도 x로 일정하게 유지됨을 의미해. 그래서 KCL은 회로에서 전류의 입출력과정에서 특정 전류의 값을 모를 때 KCL을 통해 알 수 있지."
- "KVL은 전압강하에 대한 내용으로, 하나의 loop에서 주어진 voltage가 있다면, 회로의 한 바퀴를 돌 때 일어나는 전압강하를 다 반영했을 때 V-I1R1-I2R2... = 0이 되는 법칙이야. 이것 역시, 특정 전류나 전압을 알아내기 위해 쓰여."
- "KCL, KVL모두 전류나 전압이 보존된다는 점에 있어서 에너지보존법칙?과 연결된다고 볼 수도 있을 것 같아."
- "1A가 흘러야 하지, 왜냐면 전하는 보존되지 않기 때문"
- "전하가 저항을 통과하는 과정에서 에너지가 쓰이기 때문이지, 그리고 한 바퀴안에 모든 전압을 저항에 비례하게 할당하여 에너지를 사용하기 때문"
- "이건 기억나. GND도 알고, node voltage, supernode 에 개념도 알어. 회로에서 특정 전류나 전압을 계산하는 과정은 알아."

## 오늘 직접 학습한 지식
1. KCL에서 노드로 들어오는 전류의 합과 나가는 전류의 합이 같다는 계산 원리를 기억하고 있다.
2. KVL에서 하나의 loop를 따라 전압 상승과 전압 강하를 반영하면 전압의 대수합이 0이 된다는 계산 원리를 기억하고 있다.
3. KCL은 전하 보존과 연결되고, KVL은 에너지 보존과 연결된다는 구분을 보완했다.
4. Node Analysis에서 GND, node voltage, supernode를 사용해 회로의 특정 전류나 전압을 계산한다는 내용은 단서를 주면 기억난다.

## 교정 및 보완
- KCL의 근거를 "전하는 보존되지 않기 때문"이라고 말했지만 반대다. KCL은 전하 보존 때문에 성립하며, 정상상태 노드에 전하가 계속 축적되지 않는다는 뜻이다.
- KVL에서 저항이 전압을 "할당받는다"기보다, 전원이 전하에 공급한 에너지가 저항에서 열 등으로 변환되고 한 바퀴 뒤 순에너지 변화가 0이 되기 때문에 전압의 대수합이 0이 된다.
- 단어만 제시하고 바로 설명하게 하면 기억 인출이 어렵다. 복원 세션에서는 먼저 짧은 설명이나 단서를 제시한 뒤 기억 여부를 확인하고, 이후 적용과 설명으로 검증하는 방식이 더 적합하다.

## 퀴즈
- Q1: 노드로 2A와 3A가 들어오고 4A가 나갈 때 남은 가지 전류는 얼마이며 왜 그런가? / 내 답: "1A가 흘러야 하지, 왜냐면 전하는 보존되지 않기 때문" / 채점: 수치는 정답. 근거는 반대로 말했으며 전하 보존 때문에 1A가 나가야 한다.
- Q2: 에너지 관점에서 저항의 전압 강하와 KVL을 설명하라. / 내 답: "전하가 저항을 통과하는 과정에서 에너지가 쓰이기 때문이지, 그리고 한 바퀴안에 모든 전압을 저항에 비례하게 할당하여 에너지를 사용하기 때문" / 채점: 저항에서 에너지가 변환된다는 핵심은 맞음. 한 바퀴 후 순에너지 변화가 0이라는 설명은 보완 필요.

## 취약 영역
- KCL을 전하 보존과 노드의 전하 축적 관점에서 정확히 설명하는 것
- KVL을 전원의 에너지 공급, 저항에서의 에너지 변환, 한 바퀴 후 순에너지 변화 0으로 연결해 설명하는 것
- Node Analysis, supernode는 인지 수준으로 확인했지만 아직 스스로 적용하거나 설명하는 검증은 하지 않음

## 다음 복습 질문

2. 전하가 회로를 한 바퀴 돈 뒤 KVL의 전압 대수합이 0이 되는 이유는 무엇인가?
3. 간단한 Node Analysis 회로에서 기준 노드를 정하고 KCL 식을 세울 수 있는가?

## 개념 지도
### 전자회로 기초
- KCL ← 전하 보존, 노드
- KVL ← 에너지 보존, 폐회로
- Node Analysis ← KCL, 기준 노드, node voltage
- supernode ← Node Analysis, 전압원
